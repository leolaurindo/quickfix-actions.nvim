INSTALLATION                                                   *quickfix-actions-installation*

lazy.nvim: >
  { "leolaurindo/quickfix-actions.nvim", opts = {} }
<

vim.pack (Neovim 0.12+): >
  vim.pack.add({ "https://github.com/leolaurindo/quickfix-actions.nvim" }, { load = true })
  require("quickfix_actions").setup()
<

No runtime dependencies.

SETUP                                                          *quickfix-actions-setup*

  require("quickfix_actions").setup()

The native list is canonical. Rendered quickfix buffers remain native and
read-only; use the Lua API or commands to mutate a list.

TARGETS                                                        *quickfix-actions-targets*

Targets use stable native IDs: >
  { kind = "quickfix", id = 42 }
  { kind = "location", id = 17, winid = 1001 }
<

For a location list, winid is its owning file window. Stale IDs and invalid
owners fail rather than falling back to another list.

COMMANDS                                                       *quickfix-actions-commands*

                                                        *QuickfixActionsOpen*
:QuickfixActionsOpen [quickfix|location]  Open a list.
                                                        *QuickfixActionsClose*
:QuickfixActionsClose [quickfix|location]  Close a list.
                                                       *QuickfixActionsToggle*
:QuickfixActionsToggle [quickfix|location]  Toggle a list.
                                                       *QuickfixActionsHistory*
:QuickfixActionsHistory [quickfix|location]  Open the history browser.
                                                        *QuickfixActionsPick*
:QuickfixActionsPick  Pick an entry and jump to its source.
                                                       *QuickfixActionsSearch*
:QuickfixActionsSearch  Search the current list and focus the selected row.
                                                         *QuickfixActionsJump*
:QuickfixActionsJump  Jump to the current entry.
                                                       *QuickfixActionsDelete*
:QuickfixActionsDelete  Delete the current entry.
                                                *QuickfixActionsDeleteCurrent*
:QuickfixActionsDeleteCurrent  Delete the current entry.
                                                         *QuickfixActionsClear*
:QuickfixActionsClear  Clear the current list.

Default qf-local mappings are <CR> for jump and dd for delete. Set
mappings.qf = false to install none.

LUA API                                                       *quickfix-actions-api*

The module provides read, current, item, replace, delete, delete_current,
clear, jump, select, open, close, is_open, toggle, history, open_history,
entries, pick, and search. Snapshots retain native fields and user_data.
Mutations can check changedtick.

                                                        *actions-history*
:lua require('quickfix_actions').history({ kind = 'quickfix' })
    Return live history entries with their native ID, history number, title,
    item count, and current state. Location-list history is scoped to winid.

                                                   *actions-open-history*
:lua require('quickfix_actions').open_history({ kind = 'quickfix' })
    Open history entries in a native quickfix list. Press <CR> on an entry to
    activate and open its referenced list.

|actions-search| searches the current native list by path and entry text. It uses
Snacks' compact select picker when available and focuses the selected row in the
open quickfix/location-list window without jumping to the source buffer. Without
Snacks it falls back to vim.ui.select.

                                                        *actions-search*
:lua require('quickfix_actions').search({
:  prompt = 'Search diagnostics',
:  format_item = function(entry) return entry.path .. ' - ' .. entry.text end,
:  on_confirm = function(entry)
:    return require('quickfix_actions').select(entry.list, entry.index)
:  end,
:})

                                                        *actions-select*
:lua require('quickfix_actions').select(target, index)
    Focus the native list window and place its cursor on index. This does not
    jump to the source buffer.
