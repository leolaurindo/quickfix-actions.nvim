INSTALLATION                                                   *quickfix-actions-installation*

lazy.nvim: >
  { "leolaurindo/quickfix-actions.nvim", opts = {} }
<

vim.pack (Neovim 0.12+): >
  vim.pack.add({ "https://github.com/leolaurindo/quickfix-actions.nvim" }, { load = true })
  require("quickfix_actions").setup()
<

No runtime dependencies.

SETUP                                                          *quickfix-actions-setup*

  require("quickfix_actions").setup()

The native list is canonical. Rendered quickfix buffers remain native and
read-only; use the Lua API or commands to mutate a list.

TARGETS                                                        *quickfix-actions-targets*

Targets use stable native IDs: >
  { kind = "quickfix", id = 42 }
  { kind = "location", id = 17, winid = 1001 }
<

For a location list, winid is its owning file window. Stale IDs and invalid
owners fail rather than falling back to another list.

COMMANDS                                                       *quickfix-actions-commands*

                                                       *QuickfixActionsToggle*
:QuickfixActionsToggle [quickfix|location]  Open or close a list window.

                                                  *QuickfixActionsLayoutToggle*
:QuickfixActionsLayoutToggle [quickfix|location]
    Cycle an open list bottom -> left -> top -> right -> bottom. If closed,
    open it at its remembered layout, or the configured initial layout.
                                                     *QuickfixActionsLayout*
:QuickfixActionsLayout {top|left|right|bottom} [quickfix|location]
    Reopen the current native list at the requested edge. The current list kind
    is used by default; location lists use the current file window or the owner
    of the current location-list window. Horizontal and vertical are accepted
    as aliases for bottom and right.
                                                       *QuickfixActionsHistory*
:QuickfixActionsHistory [quickfix|location]  Open the history browser.
                                                        *QuickfixActionsPick*
:QuickfixActionsPick  Pick an entry and jump to its source.
                                                       *QuickfixActionsSearch*
:QuickfixActionsSearch  Search the current list and focus the selected row.
                                                         *QuickfixActionsJump*
:QuickfixActionsJump  Jump to the current entry.
                                                       *QuickfixActionsDelete*
:QuickfixActionsDelete  Delete the current entry.
                                                *QuickfixActionsDeleteCurrent*
:QuickfixActionsDeleteCurrent  Delete the current entry.
                                                         *QuickfixActionsClear*
:QuickfixActionsClear  Clear the current list.
                                                    *QuickfixActionsAddCurrent*
:QuickfixActionsAddCurrent [id]
    Append the current file as a file-level entry to the current quickfix list,
    or to id when supplied.
                                                     *QuickfixActionsAddRange*
:[range]QuickfixActionsAddRange [id]
    Append the current file and selected range to the current quickfix list,
    or to id when supplied.
                                                      *QuickfixActionsAddFile*
:QuickfixActionsAddFile {path} [start:end] [id]
    Append a file-level entry or range to the current list, or to id when
    supplied. The optional ID is always the final argument.
                                             *QuickfixActionsAddCurrentHistory*
:QuickfixActionsAddCurrentHistory
    Choose a quickfix history list, then append the current file.
                                              *QuickfixActionsAddRangeHistory*
:[range]QuickfixActionsAddRangeHistory
    Choose a quickfix history list, then append the current file and range.
                                               *QuickfixActionsAddFileHistory*
:QuickfixActionsAddFileHistory {path} [start:end]
    Choose a quickfix history list, then append the supplied file or range.
                                                *QuickfixActionsSetText*
:QuickfixActionsSetText {text}
    Replace the current entry's text from an open quickfix/location-list window.

All add commands are quickfix-list scoped. Range commands accept a visual or
Ex line range. History selection uses stable list IDs; canceling does nothing.

Default qf-local mappings are <CR> for jump and dd for delete. Set
mappings.qf = false to install none.

LUA API                                                       *quickfix-actions-api*

The module provides read, current, item, replace, append, set_text, add_file,
delete, delete_current, clear, jump, select, open, close, is_open, toggle,
history, open_history, choose_history, entries, pick, and search. Snapshots
retain native fields and user_data. Mutations can check changedtick.

open(target, opts) accepts layout='top'|'left'|'right'|'bottom'. Left/right use
width; top/bottom use height. The existing vertical=true/width API and default
horizontal/height behavior remain supported. layout='horizontal' and
layout='vertical' remain aliases for bottom and right. Optional wrap, linebreak,
and breakindent booleans are applied only to the opened list window. toggle()
and open_history() accept these same options.

setup({ layout = 'bottom' }) sets the initial position used by
:QuickfixActionsToggle. The last runtime layout is remembered per list, and is
used when reopening it. :QuickfixActionsLayoutToggle cycles bottom, left, top,
and right.

append(target, items, expected_tick) appends native items without replacing list
metadata. set_text(target, index, text, expected_tick) changes only an item's
message. add_file(target, path, first, last, expected_tick) appends a file-level
entry or preserves a supplied range; its text is empty by default. For the
current quickfix list, pass { kind = 'quickfix' } without an id.
choose_history(callback) presents quickfix history with title and stable ID,
then calls back with { kind, id, winid }. Canceling does not mutate a list.

                                                   *actions-set-text*
:lua require('quickfix_actions').set_text(target, index, text, expected_tick)
    Change one entry's message while preserving the other entries and list
    metadata. Use the changedtick from a current() snapshot to avoid stale edits.

                                                        *actions-history*
:lua require('quickfix_actions').history({ kind = 'quickfix' })
    Return live history entries with their native ID, history number, title,
    item count, and current state. Location-list history is scoped to winid.

                                                   *actions-open-history*
:lua require('quickfix_actions').open_history({ kind = 'quickfix' })
    Open history entries in a native quickfix list. Press <CR> on an entry to
    activate and open its referenced list.

|actions-search| searches the current native list by path and entry text. It uses
Snacks' compact select picker when available and focuses the selected row in the
open quickfix/location-list window without jumping to the source buffer. Without
Snacks it falls back to vim.ui.select.

                                                        *actions-search*
:lua require('quickfix_actions').search({
:  prompt = 'Search diagnostics',
:  format_item = function(entry) return entry.path .. ' - ' .. entry.text end,
:  on_confirm = function(entry)
:    return require('quickfix_actions').select(entry.list, entry.index)
:  end,
:})

                                                        *actions-select*
:lua require('quickfix_actions').select(target, index)
    Focus the native list window and place its cursor on index. This does not
    jump to the source buffer.
